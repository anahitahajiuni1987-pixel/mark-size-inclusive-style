# Mark Size Inclusive Style

MARK – Premium 3D Men's Fashion E-commerce Website 



Design a premium, modern, cinematic and fully Persian RTL e-commerce website for MARK (مارک), a real men's fashion and accessories store located in:



اصفهان، مجتمع پارک، پوشاک مارک



The store specializes in men's plus-size fashion (سایز بزرگ مردانه), while also offering regular and smaller sizes.



IMPORTANT: This is a real commercial store. The design must communicate that MARK is a specialist destination for men who need larger clothing sizes, without making customers who wear smaller sizes feel excluded.



1. BRAND IDENTITY & VISUAL DIRECTION 



Brand name: MARK | مارک



Brand personality:



Premium Masculine Modern Confident Sophisticated Inclusive sizing 



Visual identity:



Deep black Charcoal Warm ivory Champagne or metallic silver accents Elegant typography 



Avoid excessive gold, cluttered layouts, generic templates and cheap-looking gradients.



Use high-quality men's fashion photography and realistic product imagery.



2. LANGUAGE & RTL 



The entire customer-facing website must be in Persian.



Requirements:



Full RTL layout. Persian typography using Vazirmatn or a similarly elegant Persian font. Persian navigation and product descriptions. Persian Toman prices with readable formatting. Persian user-friendly forms. Mobile-first responsive design. 



Keep product brand names such as MARK in Latin characters where appropriate.



3. PAGE ONE: HOMEPAGE 



Create a visually impressive cinematic 3D homepage.



Hero section 



A full-screen luxury men's fashion scene.



Show a stylish male model wearing modern men's clothing in a premium dark studio.



Use subtle 3D camera movement, depth, lighting and scroll-controlled transitions.



Main headline:



«استایل بزرگ، انتخاب بی‌نهایت»



Supporting text:



«پوشاک مردانه از سایزهای معمولی تا سایزهای بزرگ؛ با تنوعی که استایل شما شایسته آن است.»



Primary CTA: «مشاهده محصولات»



Secondary CTA: «کالکشن سایز بزرگ»



Main navigation صفحه اصلی پوشاک مردانه سایز بزرگ کفش اکسسوری جدیدترین‌ها تماس با ما 



Include a search icon, user account icon and shopping cart.



Product categories 



Create beautiful visual category cards for:



پوشاک مردانه



تیشرت پولوشرت پیراهن شلوار شلوارک سویشرت هودی کاپشن و کت 



اکسسوری مردانه



عطر کمربند کیف کلاه جوراب کراوات 



کفش



کفش رسمی کفش اسپرت کفش روزمره Special plus-size section 



This is one of the most important sections of MARK.



Create a distinctive premium section titled:



«استایل برای تمام سایزها»



Subtitle: «تخصص ما، انتخاب راحت‌تر شماست.»



Highlight:



تنوع سایزهای بزرگ مردانه راهنمای دقیق اندازه‌ها فیلتر براساس سایز پوشاک مناسب اندام‌های درشت امکان انتخاب سایزهای معمولی و کوچک‌تر نیز وجود دارد. 



Do not portray plus-size customers as a separate or inferior audience.



Additional homepage sections جدیدترین محصولات پرفروش‌ترین‌ها پیشنهاد ویژه کالکشن منتخب مارک محصولات سایز بزرگ محصولات منتخب کفش و اکسسوری معرفی فروشگاه MARK آدرس فروشگاه و نقشه فوتر حرفه‌ای 



Store address: «اصفهان، مجتمع پارک، پوشاک مارک»



Add a prominent CTA: «مسیریابی فروشگاه»



4. PAGE TWO: PRODUCT DETAIL PAGE 



Design a premium product detail page with an immersive product gallery.



Include:



Large product photography Multiple product images Image zoom Product name Price Discount price when applicable Product description Product availability Color selection Size selection Quantity selector Add to cart button Buy now button Related products Advanced size selection 



This is especially important for MARK.



For clothing products:



Display all available sizes dynamically. Support regular and plus sizes. Allow size options such as S, M, L, XL, XXL, 3XL, 4XL, 5XL and larger sizes when available. Never show unavailable sizes as purchasable. Include a size guide with body measurements in centimeters. Make it easy to understand the difference between clothing size and actual body measurements. 



For shoes:



Display shoe sizes based on the actual available inventory. Support size selection before adding to cart. 



For accessories and perfumes:



Display relevant options such as volume, color, dimensions or size depending on the product. 



Show stock availability clearly.



5. PAGE THREE: CHECKOUT / PAYMENT 



Create a clean, trustworthy, Persian RTL checkout experience.



Sections:



Customer information نام و نام خانوادگی شماره موبایل استان شهر آدرس کامل کد پستی توضیحات سفارش (اختیاری) Order summary Product image Product name Selected color Selected size Quantity Unit price Total price Payment Display the available payment methods based on actual backend configuration. Show final payable amount. Include a clear order confirmation button. 



Important: Never simulate a successful payment. Never display a fake payment gateway. Only show online payment as available when a real payment provider is properly configured.



Include a final order review before payment.



6. 3D EXPERIENCE & ANIMATIONS 



Use a sophisticated 3D visual experience, not excessive animations.



Three.js or React Three Fiber where appropriate. GSAP ScrollTrigger for cinematic scrolling. Smooth transitions between homepage sections. 3D product presentation. Subtle parallax effects. Premium hover interactions. Smooth mobile animations. 



Optimize performance. Provide lightweight fallbacks for mobile devices.



7. CUSTOMER EXPERIENCE 



The website must feel like a professional real-world Iranian fashion store.



Responsive mobile and desktop. Fast loading. Easy shopping navigation. Clear pricing. Easy product discovery. Accessible buttons. Consistent Persian RTL design. 8. IMPLEMENTATION SCOPE 



Build only these three customer-facing pages in this phase:



Homepage Product detail page Checkout/payment page 



Use realistic sample products and imagery if actual product data is not yet connected.



Do not invent actual inventory, prices, payment success or store contact details.



If an existing MARK project is provided, preserve its existing backend, authentication, product data, shopping cart and business logic. Do not replace or damage working functionality.



The final result should look like a high-end international men's fashion brand website, with a distinctive identity centered on inclusive sizing and plus-size men's fashion.
